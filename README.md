# FastAPI Learning 🚀

A structured repository for learning **FastAPI** from fundamentals to advanced concepts through practical examples and hands-on projects.

## 🎯 Objective

The goal of this repository is to build a strong understanding of FastAPI and REST API development using Python.

* First FastAPI Application
* Routes and Endpoints

* Path Parameters

* Practical Projects

## ⚙️ Project Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/FastAPI-Learning.git
cd FastAPI-Learning
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the virtual environment

Windows:

```bash
venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

## 📖 API Documentation

FastAPI automatically provides interactive API documentation.

Once an application is running:

* Swagger UI: `http://127.0.0.1:8000/docs`
* ReDoc: `http://127.0.0.1:8000/redoc`
